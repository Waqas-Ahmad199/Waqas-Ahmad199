# Upload steps (Waqas-Ahmad199)

1. Repository name MUST be exactly `Waqas-Ahmad199` (Settings > General > Repository name).
2. Add file > Upload files. Drag in EVERYTHING inside this folder: README.md, assets, scripts and .github.
   If .github is not visible, turn on "Show hidden items" in File Explorer (View > Show > Hidden items).
3. Commit directly to main.
4. Settings > Actions > General > Workflow permissions > Read and write permissions > Save.
5. Actions tab > Update profile > Run workflow. Wait 1 minute.
6. Open github.com/Waqas-Ahmad199 and refresh.
